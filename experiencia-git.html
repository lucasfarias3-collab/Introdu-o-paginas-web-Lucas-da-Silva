Minha Experiência com Git

Eu já conhecia o GitHub e já havia utilizado a plataforma para publicar atividades da disciplina. Porém, ainda tinha dificuldades com alguns comandos do Git utilizados no terminal.

A principal dificuldade encontrada foi clonar um repositório para o computador e entender o processo de trabalhar com um repositório local e remoto. Também tive dúvidas sobre alguns comandos necessários para realizar as alterações e enviá-las para o GitHub.

Para resolver essas dificuldades, pedi ajuda aos colegas de turma e utilizei uma IA para entender melhor os comandos e o passo a passo necessário para realizar a atividade.

Com essa ajuda, consegui clonar o repositório, adicionar arquivos, realizar commits e enviar as alterações para o repositório remoto utilizando o Git.

A atividade foi importante para ampliar meus conhecimentos sobre controle de versão e compreender melhor como o Git e o GitHub podem ser utilizados no desenvolvimento de projetos.
